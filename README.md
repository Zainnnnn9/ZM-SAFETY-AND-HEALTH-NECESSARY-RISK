# Necessary Risk

**How the global supply chain depends on controlled danger to survive.**

An interactive research publication by **ZM Safety & Risk** (ZMSR-RS-01).

Most safety programs investigate the incident. This study looks at the
system that keeps producing it. It maps six feedback loops that hold harm
in place across global supply chains:

- **R1 Fatigue vs. productivity**
- **R2 Procurement pressure**
- **R3 Automation trade-offs**
- **B1 Regulatory delay**
- **R4 Environmental rebound**
- **B2 Underreporting**

Each loop is backed by published data and paired with a leverage point.
